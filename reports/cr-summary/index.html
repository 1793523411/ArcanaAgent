CR 发现并修复的问题

P1

Opus 4.7 不能被配置覆盖成 manual thinking

之前虽然默认走 adaptive，但用户在模型配置里选 manual 仍可能重新触发 400。现在 claude-opus-4-7 在解析层强制 adaptive。

P2

非 Opus 4.7 不应发送 xhigh effort

xhigh 官方只标给 Opus 4.7。现在 Sonnet 4.6 / Opus 4.6 如果配置了 xhigh，会降回 high。

P2

plan completed 后不能再回退成 running

补最终答复的流式 token 可能晚于 completed 事件到达。现在加了终态保护，避免前端计划状态闪回。

P3

plan 文本识别不能把否定句当完成

收紧了“未完成 / 不通过”的识别边界，并补了单测。

影响面判断

  • 模型请求影响集中在 Anthropic thinking 参数构造。
  • OpenAI 兼容模型只保留原有 reasoning 开关和 temperature 行为。
  • plan 修复只影响流式 plan event，不改最终答案内容。
  • 配置 UI 新增字段会被后端再次校验，不能直接发出不支持参数。
